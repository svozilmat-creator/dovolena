# Datový model

Viz `destination.schema.example.json`, což je komentovaný JSONC příklad. Produkční `destinations.json` je validní JSON bez komentářů. Hodnocení je 0–10; vyšší je lepší, s výjimkou `tourism`, kde vyšší znamená více turistů. Měsíce v `seasonality` jsou klíče `1` až `12`. Ceny jsou intervaly, nikoli garantované částky.
